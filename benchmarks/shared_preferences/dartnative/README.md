# shared_preferences benchmark, DartNative app

One of the two apps of the shared_preferences benchmark.
[../README.md](../README.md) explains what is measured and gives the
results; the commands to run the app are at the top of `lib/main.dart`.
`lib/benchmark/` is the benchmark code; `../flutter/lib/benchmark/` holds
the same files with two lines changed, kept equal by
`../tool/sync_flutter.sh`.
