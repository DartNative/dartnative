# DartNative first-party plugins

Every folder here documents a **first-party plugin** — camera, video, maps,
notifications, storage, connectivity, on-device AI and more. Browse the catalog
and install any of them from [dartpub.dev](https://dartpub.dev), where each
plugin also has a runnable example. All of them are **free**.

## Where's the source?

The core plugins are part of the supported DartNative product: **one team, one
quality bar**. They ship as maintained binaries with your framework
subscription, they're kept compatible with the current framework, and issues
are handled right here in this repository — that's what the subscription pays for.
We don't take PRs on the core, for the same reason a warranty means one workshop.

Around that core, the **community plugin layer is fully open source** — every
community plugin on dartpub.dev links its public repository (MIT/BSD/Apache), can
be forked and fixed by anyone, and every published version is archived by the
registry, so a dependency can never disappear.

And the worst case is in writing, not in goodwill: DartNative's license carries a
**sunset commitment** — if the framework is ever discontinued, the framework *and*
these core plugins are released publicly under BSD-3. Nothing here can be orphaned.
Read the full terms at [dartnative.com/license](https://dartnative.com/license).

## Reporting issues

Open an issue in this repository with the plugin's name in the title (per-plugin
labels are applied during triage). For community plugins, use the issue tracker of
the plugin's own repository, linked from its dartpub.dev page.
