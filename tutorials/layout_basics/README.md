# Layout that thinks in widgets

The finished code for the [layout tutorial](https://dartnative.com/tutorials/layout-basics):
a profile card screen built from the core layout vocabulary — `Row`,
`Column`, `Stack`, `Padding`, `Expanded` — each widget driving a real
native view laid out by Yoga with Flutter's sizing rules.

```sh
dn pub get
dn run
```

The whole app is one file: [`lib/main.dart`](lib/main.dart).
Verified against dartnative `^1.0.0`.
