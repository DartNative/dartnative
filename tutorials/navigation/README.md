# Navigation & routes

The finished code for the [navigation tutorial](https://dartnative.com/tutorials/navigation):
pushed screens with native transitions, named routes, a modal presentation,
and the platform back gestures — all through the Flutter `Navigator` API.

```sh
dn pub get
dn run
```

The whole app is one file: [`lib/main.dart`](lib/main.dart).
Verified against dartnative `^1.0.0`.
